# 📝 Glassmorphism To-Do List App

A modern and interactive To-Do List web application built with **HTML, CSS, and JavaScript**, featuring a clean glassmorphism UI and dynamic task management.

---

## 🚀 Features

- Add, edit, and delete tasks  
- Mark tasks as completed  
- Dynamic progress bar tracking  
- Confetti animation when all tasks are completed 🎉  
- Data persistence using **localStorage**  
- Responsive glassmorphism design  

---

## 🛠️ Technologies Used

- HTML5  
- CSS3 (Glassmorphism UI)  
- JavaScript (Vanilla JS)  
- Font Awesome (icons)  
- Canvas Confetti
